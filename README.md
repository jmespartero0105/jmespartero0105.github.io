# Janus Marco L. Espartero — Personal Portfolio

A minimalist, bold, and modern personal portfolio website tailored for a 4th-year Bachelor of Science in Information Technology student. The design elegantly balances a highly technical aesthetic with creative, fine-art photography sensibilities.

## About

This project was built to present a realistic, high-end developer identity. It serves as a centralized hub to showcase my software engineering projects, educational achievements, technical skills, and photography awards. The repository contains a single cohesive codebase optimized for GitHub Pages, with zero backend or framework dependencies.

## Technologies

* **HTML5**: Semantic and accessible document structure.
* **CSS3**: Custom variables, Grid/Flexbox layouts, responsive design, and smooth transitions.
* **JavaScript (Vanilla)**: Mobile navigation, dynamic year injection, scroll spy, scroll intersection animations, and an interactive image carousel.

## Projects Featured

1. **SUMPAY**: Flutter emergency and response application with offline functionality.
2. **MeeehPortfolio**: ReactJS personal information showcase.
3. **Meme Generator**: ReactJS application utilizing a public API.

## Features

* **Responsive Design**: Flawless layouts from large desktops down to 320px mobile screens.
* **Dark Minimalist Interface**: Professional high-contrast dark theme (`#080808` core background).
* **Graceful Asset Fallbacks**: Intelligent SVG/CSS geometric placeholders handle missing images elegantly until real assets are uploaded.
* **Accessibility**: Includes `prefers-reduced-motion` queries, semantic tags, and distinct visual hierarchies.
* **No Dependencies**: 100% vanilla web technologies.
